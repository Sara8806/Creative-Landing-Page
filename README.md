# Creative Landing Page

A creative landing page built using HTML5 and CSS3.

## Features
- Fixed navigation bar
- Hero section with a background image
- About and services sections
- Portfolio image gallery
- Contact form layout
- Smooth scrolling navigation
- Hover effects

## Technologies Used
- HTML5
- CSS3
- CSS Grid
- Flexbox

## Project Structure
- `index.html` — Main HTML page
- `style.css` — Website styling
- `image/` — Website images

## How to Run
Download or clone this repository and open `index.html` in your browser. You can also use VS Code with Live Server.

## Note
This is a front-end practice project. The contact form is a visual layout and does not currently send messages.
